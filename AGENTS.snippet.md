## UI
This project's UI uses Frame UI, a no-build kit that lives in `./frame/` (or is hosted at https://YOUR-HOST/).
Before writing or changing any screen read `frame/AGENTS.md` (hosted: https://YOUR-HOST/llms-full.txt).
Use only its `f-` classes, copy page templates from `frame/pages/`, no custom CSS/JS, then check the page with `data-check`.
