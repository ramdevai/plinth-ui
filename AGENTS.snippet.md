## UI
This project's UI uses Plinth, a no-build kit that lives in `./plinth/` (or is hosted at https://plinth.pages.dev/).
Before writing or changing any screen read `plinth/AGENTS.md` (hosted: https://plinth.pages.dev/llms-full.txt).
Use only its `f-` classes, copy page templates from `plinth/pages/`, no custom CSS/JS, then check the page with `data-check`.
